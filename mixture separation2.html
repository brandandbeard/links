📖 পাতন (Distillation)

তরল মিশ্রণ/দ্রবণকে ফুটিয়ে বাষ্প করে, সেই বাষ্পকে কনডেনসারে ঘনীভূত করে বিশুদ্ধ তরল পৃথক করার পদ্ধতি। শর্ত: দ্রব অউদ্বায়ী / স্ফুটনাঙ্কের ব্যবধান বেশি।
📚 উদাহরণ ব্যাংক (★ = গুরুত্ব)
  • ★★★ লবণ / চিনির জল → বিশুদ্ধ জল (১০০°C) + কঠিন অবশিষ্ট
  • ★★★ পাতিত জল (distilled water) প্রস্তুতি — নদী/সমুদ্রের জল থেকে
  • ★★★ CuSO₄·5H₂O দ্রবণ → বিশুদ্ধ জল; ফ্লাস্কে কপার সালফেট কেলাস
  • ★★ অবিশুদ্ধ ক্লোরোফর্ম → বিশুদ্ধ ক্লোরোফর্ম (৬১°C)
  • ★★ আইওডিন — বেগুনি বাষ্প → কেলাস (মূলত ঊর্ধ্বপাতন; নীতি একই)
  • ★ সমুদ্রের জল থেকে মিঠা জল (desalination)
🎯 পরীক্ষার টিপস
পাতনের দুই ধাপ লিখবে: বাষ্পীভবন + ঘনীভবন। গ্রাফে স্ফুটনাঙ্কে প্লাটো দেখাও। ঊর্ধ্বপাতনের উদাহরণ: আইওডিন, অ্যামোনিয়াম ক্লোরাইড, কর্পূর — এগুলো পাতন নয়!

🔥 তাপ0%
25 °C
প্রিসেট বেছে ▶ চাপুন। ল্যাব = ফ্র্যাকশনেটিং কলাম; শিল্প = উচ্চ স্তম্ভ।

📖 আংশিক পাতন (Fractional Distillation)

স্ফুটনাঙ্কের ব্যবধান কম (~৩০°C‑এর কম) হলে ফ্র্যাকশনেটিং কলাম-সহ পাতন — উপাদানগুলো স্ফুটনাঙ্কের ক্রমানুসারে পৃথক হয়।
📚 উদাহরণ ব্যাংক (★ = গুরুত্ব)
  • ★★★ অ্যাসিটোন (৫°C) + মিথাইল অ্যালকোহল (৬৫°C)
  • ★★★ পেট্রোলিয়াম → পেট্রোল, কেরোসিন, ডিজেল, লুব তেল, বিটুমেন
  • ★★★ তরল বায়ু → নাইট্রোজেন (−১৯৬°C), আর্গন (−১৮৬°C), অক্সিজেন (−১৮৩°C)
  • ★★ আলকাতরা → বেঞ্জিন (৮০°C), টলুইন, ফিনল, ন্যাফথালিন, পিচ
  • ★★ জল + ইথাইল অ্যালকোহল (মদ্যসার শুদ্ধিকরণ, ৭৮°C আগে)
  • ★ বেনজিন + টলুইন মিশ্রণ
🎯 পরীক্ষার টিপস
কলামের কাজ: বারবার ঘনীভবন‑বাষ্পীভবন। পেট্রোলিয়াম স্তম্ভে উপরে ঠান্ডা‑নিচে তপ্ত; কম স্ফুটনাঙ্ক = উপরে জমা। তরল বায়ুতে আগে নাইট্রোজেন বেরোয়।

🎛️ নিয়ন্ত্রণ

অমিশ্রণীয় তরল স্থির — ঘনত্ব অনুযায়ী স্তর দেখো।

📖 বিভাজক ফানেল (Separatory Funnel)

অমিশ্রণীয় + ঘনত্বের পার্থক্যযুক্ত তরল → স্থির রাখলে দুই স্তর; ভারীটি নিচে। স্টপকক খুলে নিচেরটি আলাদা; উপরেরটি মুখ থেকে ঢালা হয়।
📚 উদাহরণ ব্যাংক (★ = গুরুত্ব)
  • ★★★ ক্লোরোফর্ম (১.৪৮) + জল — ক্লোরোফর্ম নিচে
  • ★★★ পেট্রোল (০.৭) + জল — পেট্রোল উপরে
  • ★★ পারদ (১৩.৬) + জল — পারদ নিচে
  • ★★ কার্বন টেট্রাক্লোরাইড CCl₄ (১.৫৯) + জল — CCl₄ নিচে
  • ★ বেনজিন (০.৮৭) + জল — বেনজিন উপরে
🎯 পরীক্ষার টিপস
কোনটি নিচে তা ঘনত্ব ঠিক করে। জলের ঘনত্ব ১.০ g/cc ধরে তুলনা করো। বিভাজক ফানেল দিয়ে মিশ্র (miscible) তরল আলাদা করা যায় না।
